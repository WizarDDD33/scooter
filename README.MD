# API-автотест: создание заказа и получение по треку

Проект проверяет сценарий:
1. Клиент создаёт заказ.
2. Сохраняется трек заказа.
3. Заказ запрашивается по треку.
4. Проверяется, что код ответа равен 200.

## Требования
- Python 3.8+
- pytest
- requests
